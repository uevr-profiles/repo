## Description

6DOF profile V1.01 for Test build prior to 1.3

changelog:
1.01 fixed Bunker Map not working

Features:
- Hands
- Recoil
- Most stuff should be playable

Buttons:
A: sprint
B: Firemode
RStick Up: jump
RStick Down: Crouch
DPAD: Key1-4, Weapons and GPS or use holsters
Y: Use/Interact, you need to hold RGrip to aim the interaction
RightStick: works like mouse
Left Hand Trigger at Magazin: Reload or Mag Check
hold both Left Grip(first) + LeftTrigger: to go into ADS mode for less recoil

Holsters:
Right Shoulder: Primary
Right Hip: Secondary
Left Shoulder: 2nd Primary
Right Chest: Tablet

Issues:
- With all the hands stuff there´s a slight memory leak due to UE5.6, you should probably be fine at 32 gb ram to run at least 2-3 long missions, but check back your ram after every mission.
- When Holding RGrip for interaction aiming, the attachements will glitch out, but go back to  normal once release rGrip
