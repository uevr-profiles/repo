## Description

This profile has attached guns for the main game as well as DLC 1 and DLC2.
Dash and jump buttons are mapped to the right controller buttons, the circle menu is mapped to the grip button of left controller and glove skills are on the x button of the left controller.
This is using the remapping in the UI - think that might only work if you're using OpenXR Runtime.  Profile also has head gestures set for the dpad (hold right controller up to your head to use it as the dpad - you can change it in the UEVR UI so that dpad is activated with the left or right thumbpads instead).
Remember to change the name of the zip to AtomicHeart-WinGDK-Shipping.zip if using GamePass version
