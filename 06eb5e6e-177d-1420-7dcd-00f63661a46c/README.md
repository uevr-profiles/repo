## Description

Here are my recommended settings and custom profile.

- (Optional) Run DLSS Swapper and inject the latest DLSS dll for the game.
- Configure the ingame Graphics settings
- Go to this folder: %localappdata%\Dakar2Game\Saved\Config\WindowsNoEditor\
Edit: Engine.ini
Add this to the bottom:

[SystemSettings]
r.LensFlareQuality=0

- (Optional) Make sure you disable HAGS (right-click desktop > Display settings > Graphics > Advanced graphics settings)
- Run UEVR and import the attached profile.
- Run the game, go to garage, tab out and inject.

If you play in cockpit mode:
- Be sure to assign a button to wiper. The windshield gets dirty quickly.
- Assign a button to look back, and at the start of a race, quickly glance back. This fixes the missing hands in VR.

I recommend playing with the ingame UI completely disabled. The game is perfectly playable without it, and it spoils the immersion.
