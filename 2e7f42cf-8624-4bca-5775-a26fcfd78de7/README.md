## Description

6DOF Motion Control Profile (Work in Progress)

Features:
- Both arms work
- Items attach to the right arm

Known Issues:
- You must use the Adjust Tool on every launch for the right arm
    - Takes only a few seconds — see the pinned tutorial
- When using gravity platforms, the angle may be incorrect
- Finger movement is not implemented yet (planned for a future update)
