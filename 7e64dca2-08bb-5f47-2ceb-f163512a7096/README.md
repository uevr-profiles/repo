## Description

- Full 6DOF, no arms.
- All the accessories on the left are Hidden, so they don't constantly float around.
- HUD fixed to the weapon to have a precise Crosshair when shooting
- X and B button switched in OpenXR to be able to Dodge while moving
- D-pad on right Thumbstick and left Thumb rest
- A bit SS to make it less blurry, but you can tune it down for performance

Remember to switch to DX12 for better performance.
