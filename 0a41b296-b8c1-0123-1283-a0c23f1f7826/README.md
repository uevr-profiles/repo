## Description

This is a full profile, no more complicated instructions. Use nightly build 1040 or newer.

This profile updates cvars, moves the cvars out of its own plugin into user_script.txt, removes the need for the 3dmigoto since we have native fix. Please make sure you're using a nightly build 1040 or newer. You should be able to just import this profile and play the game.

Game requires DX11 mode, so make sure you add -d3d11 to your command line in steam.  Only supports openxr not openvr so make sure you inject openxr.

Make sure you're in windowed mode.
