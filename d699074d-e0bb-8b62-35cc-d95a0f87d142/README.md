## Description

Routine 6DOF Profile v0.51

Changes:
- Fixed interacting with screens.

Install:
1/ Install this mod: https://www.nexusmods.com/routine/mods/1

EVERY TIME you boot the game you need to open console and enter
rpp fisheye 0
rpp sharpen 0

2/ Go to %localappdata%\Routine\Saved\Config\Windows\GameUserSettings.ini and set sg.ResolutionQuality to something other than 0. I have a 5090 and struggle above 80.

3/ Go to your video options & disable film grain.

Notes:
NO HANDS YET
- Lean only works correctly facing forward in the center of your play space (idk if this is really needed with 6dof outside of the tutorial)
- Annoying meshes auto hidden
- Weapon auto attach
- Computer pointer trace is lined up with the CAT
- Fixed crosshair. if you point at an interactable with the crosshair on the cat, youll see the interaction crosshair pop up above the cat
- Fixed inspect mode. once you press the inspect key, youll get a laser pointer. point the laser at the buttons and press right trigger. you can also use this to control computers with your other hand (default is cat hand)
