## Description

Full 6DOF Profile

- Flashlight Attached to Left Motion
- Re-Sized UI/Crosshair
- CVAR list to improve the TAA quality

Note:
HIGHLY RECOMMENDED CHANGING SETTINGS IN APPDATA

- Go here: %localappdata%\ChromaGun2\Saved\Config\Windows\GameUserSettings.ini

In GameUserSettings.ini, change the values to those below, save and Right Click on file > Properties and check 'Read Only':

;METADATA=(Diff=true, UseCommands=true)
[ScalabilityGroups]
sg.ResolutionQuality=80
sg.ViewDistanceQuality=3
sg.AntiAliasingQuality=2
sg.ShadowQuality=2
sg.GlobalIlluminationQuality=2
sg.ReflectionQuality=2
sg.PostProcessQuality=1
sg.TextureQuality=3
sg.EffectsQuality=3
sg.FoliageQuality=2
sg.ShadingQuality=3
sg.LandscapeQuality=3
