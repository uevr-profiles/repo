## Description

Recommend to decouple the pitch of the camera as it's always by default slightly facing down. In the components of the Acknowledged you'll find a helmet mesh. Just turn the legacy visibility off in the menu otherwise you have the helmet overlapping. Just move the camera down and back for preference with each car.

You can turn off depth of field in the cvars, depending on taste, for first person turned it off, but for the wide far camera view still looks quite nice. Changing the world scale to miniature also really suits for that camera angle.

The UI all looks fine, again recommend toggling the auto adjust UI so it's flat to the horizon at the same step as decoupled pitch. Looks good if you set the UI to cylinder from quad as gives it a nice curve to it when driving.

The culling circle in the center of the camera for bridges etc. for flatscreen is a little bit annoying so would be good to have an option to disable that before someone finds it in the components to disable it.
