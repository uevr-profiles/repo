## Description

Update, new Holster system, weapons properly aligned and oriented.

Instructions:
- Import profile as usual

Ingame Rebinding:
- Bind sprint as a 2ndary key to "N"
- Bind Crouch to C and roll to something else

Motion Gestures:
- RGrip
+ Shoulders or rHip is weapons
+ RChest for Grenade, release RGrip to throw

- LGrip + Lhip = melee weapon
+lower center back = Journal
+ Lshoulder = Map

- Swing for Melee(if you have not toggled on melee without aim toggle in game settings, then you need to press Ltrigger as well)

Misc:
- Jump and Crouch with the Right stick up and down.
- Mouse Cursor can be controlled with Rstick. Mouse Click by triggers
